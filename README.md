# 🎓 NEC Campus App

A full-featured mobile application built to digitize and streamline academic operations at Nepal Engineering College (NEC). Designed for both students and faculty, this app provides real-time academic tracking, secure authentication, and offline-first capabilities to ensure uninterrupted access.

## 🚀 Key Features

### 🧑‍🎓 Student Portal
* **Real-Time Academics:** Instant access to subject-wise notes, assignments, and syllabi synced via Cloud Firestore.
* **Performance Tracking:** View marks and academic progress seamlessly.

### 👨‍🏫 Teacher Portal
* **Classroom Management:** Upload lecture notes, post assignments, and manage mark sheets directly from the app.
* **Streamlined Operations:** Centralized dashboard for handling day-to-day faculty tasks.

### 📊 Offline-Capable Attendance
* **Batch-Level Tracking:** Efficiently take attendance for entire batches.
* **Offline-First Engineering:** Log attendance without an internet connection; records are cached locally and automatically synced when reconnected.
* **Export Options:** Instantly export attendance records to CSV formats.

### 🔔 Notice Board & Communication
* **Role-Based Distribution:** Targeted notice delivery ensuring students, teachers, and HODs only see what is relevant to them.

## 🛠️ Technical Stack

* **Frontend:** Flutter / Dart (Cross-platform UI/UX)
* **Backend:** Firebase (Firestore, Authentication, Cloud Storage)
* **Architecture:** Offline-first caching mechanisms, secure role-based access control (RBAC), and real-time cloud database integration.
